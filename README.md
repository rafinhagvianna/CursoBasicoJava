# Repositório de Exercícios de Java

Este repositório contém uma coleção de exercícios de Java, realizados durante minha estadia no Senai de Londrina , abrangendo desde os conceitos mais básicos da linguagem até os fundamentos da programação orientada a objetos. O objetivo deste repositório é fornecer uma série de desafios para ajudar iniciantes e desenvolvedores em nível intermediário a praticar e aprimorar suas habilidades em Java.

## Estrutura do Repositório

O repositório é organizado da seguinte maneira:

- **18 listas de exercícios**, cada uma contendo uma média de 20 exercícios.
- Cada lista de exercícios cobre diferentes tópicos de Java, desde o básico até os conceitos de orientação a objetos.

## Tópicos Abordados

Os exercícios estão distribuídos nas seguintes áreas:

1. **Fundamentos de Java**
   - Tipos de dados, variáveis e operadores
   - Controle de fluxo (if, else, switch, loops)
   - Estruturas de dados básicas (arrays, listas)

2. **Programação Orientada a Objetos (OOP)**
   - Classes e objetos
   - Encapsulamento
   - Herança
   - Polimorfismo
   - Abstração e interfaces

3. **Coleções e Generics**
   - Listas, conjuntos, mapas e outros tipos de coleção
   - Uso de Generics

4. **Exceções e Tratamento de Erros**
   - Manipulação de exceções com try-catch
   - Criação de exceções personalizadas

5. **Entrada e Saída de Dados**
   - Leitura e escrita de arquivos
   - Serialização de objetos
